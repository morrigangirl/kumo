Kumo 0.1.0

Native macOS browser based on Chromium, with Chrome Web Store extensions,
themes, configurable search, native Apple Passwords controls and opt-in browser
tools for Codex Desktop and Claude Desktop.

Includes local known-dangerous-domain blocking and a sandboxed download
scanner using the separately installed official ClamAV runtime. The
experimental PhishLang model is omitted from this public binary. Browser app
updates use signed GitHub Release assets.

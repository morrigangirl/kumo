Kumo 0.1.1

Updates the browser engine to Chromium 156.0.8078.47, incorporating the October 20
stable security update. The local macOS build uses the matching official compiler
and Rust tools, retaining upstream Rust parsing and security checks.

Keeps downloads held during antivirus scanning. If only file metadata changes
while the bytes and file identity remain intact, Kumo performs one fresh scan
and repeats its strict tamper checks. Repeated changes still block completion.

Adds optional, on-device phishing warnings using the PhishLang MobileBERT model
and a sandboxed native Swift/Core ML helper. No separate extension, AI account or
cloud inference service is required. Enable local warnings in Kumo Settings →
Privacy & security and approve website access. Warnings start off and can be
disabled at any time.

Page analysis stays on the Mac and excludes filled form values, editable content,
scripts and private tabs. The model remains experimental and can produce false
positives or miss phishing sites. It analyzes pages after they load; it does not
replace the existing dangerous-domain blocking or download antivirus controls.

PhishLang: Sayak Saha Roy and Shirin Nilizadeh, “PhishLang: A Real-Time, Fully
Client-Side Phishing Detection Framework Using MobileBERT,” arXiv:2408.05667,
https://arxiv.org/abs/2408.05667. Paper license: Creative Commons Attribution 4.0,
https://creativecommons.org/licenses/by/4.0/. Kumo converts the checkpoint to
Core ML and changes its runtime and page representation; no author endorsement
is implied. The bundled notices retain attribution and describe these
modifications.

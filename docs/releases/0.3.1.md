Kumo 0.3.1 introduces RELAY, a native browser frame with a dark toolbar, compact angular address field, vertical tab rail, corner accents and illumination around all four window edges.

- Choose your accent color, a steady glow or slow pulse, and its intensity in Settings → Kumo → RELAY appearance. Activate RELAY frame switches to the complete native treatment, including when another theme was selected.
- Subtle tab transitions and the perimeter pulse respect the motion preference and macOS Reduce Motion. The perimeter pauses when inactive and hides in fullscreen.
- Mission Memory keeps named missions, notes, next steps and explicitly selected tab sources locally. Resume saved sources without replacing your existing tabs.
- Optional read-only MCP tools let Codex or Claude collate only the missions you explicitly share. Mission sharing is off on startup, separate from live-tab access, and revocable. An AI client may send shared content to its provider.

RELAY, Mission Memory and client setup are native browser features. To refresh an existing client's MCP tool list, use Settings → Kumo → Connect Codex Desktop or Connect Claude Desktop, then restart that client.

Use the Apple Silicon .pkg for a complete installation or dependency repair, including the bundled antivirus dependencies. The browser ZIP and automatic updates preserve profiles and explicit protection choices; they do not install missing ClamAV dependencies. PhishLang remains experimental and defaults on only for new or unset preferences. Built-in Apple Passwords integration remains removed; third-party password extensions are supported.

Widevine-protected streaming remains unavailable pending licensing and integration. Mission checkpoints do not record page content, cookies, form fields, scroll positions or window geometry. Saved source URLs omit query strings and fragments.

Validation includes native tests, overlay/package checks, headed browser integration checks, and live frame, menu, fullscreen, resize and pulse inspection. Clean-machine administrator installation, system-level rollback and interrupted-install recovery retain the earlier release's qualification limits; they have not been qualified on a separate Mac.

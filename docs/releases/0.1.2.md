Kumo 0.1.2

Removes Kumo's built-in Apple Passwords integration: the custom context-menu
action, native credential sheet, settings panel, and experimental pairing and
SDK components. Use your preferred password extension instead. Normal Chromium
extension support, WebAuthn and saved website sessions are retained.

Retains Chromium 156.0.8078.47, local dangerous-domain blocking, ClamAV download
scanning, optional on-device PhishLang warnings, and signed GitHub updates.
PhishLang warnings remain off by default; model attribution and change notices
remain bundled with the application.

Widevine DRM is not included. Protected video playback that requires Widevine
is unavailable; the reported Crunchyroll playback issue remains unresolved.

Kumo 0.1.2

Clarifies the native Apple Passwords fill dialog and its instructions. In Apple's
chooser, select the website or app entry and the saved account, then click Fill
after the selected username or password appears in Kumo's native field.

The existing manual Apple Passwords flow remains available. Inline account
suggestions and pairing at browser startup are not enabled in this release.
Apple's browser helper currently cannot establish a connection with Kumo;
browser-list inclusion has been requested at
https://github.com/apple/password-manager-resources/issues/1849.

Retains Chromium 156.0.8078.47, local dangerous-domain blocking, ClamAV download
scanning, optional on-device PhishLang warnings, and signed GitHub updates.
PhishLang warnings remain off by default; model attribution and change notices
remain bundled with the application.

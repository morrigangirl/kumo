Kumo 0.2.0

Build: 202610210004.

Moves Kumo's controls into the browser's own Settings, menus and new-tab page.
The Kumo product extension is removed; ordinary third-party extensions and
Chrome Store themes remain supported. Browser-owned settings handle search,
appearance, protections, desktop AI connections and updates.

Moves dangerous-domain blocking and local PhishLang classification into native
browser services. PhishLang starts enabled for new profiles and previously
unset preferences, while existing explicit opt-outs are preserved. Analysis
uses a bounded local page representation; no cloud model or extension website
permission is required. Missing or initializing protection is reported honestly.
The model remains experimental and can produce false positives or miss threats.
Attribution, the owner's recorded distribution decision and change notices
remain bundled.

Adds browser-owned Codex and Claude connection/setup controls with a bundled
agent runtime. Desktop AI browser access starts disabled; the user controls
which tabs and origins an agent may use and can revoke access. Agent access
does not confer installer, updater or unrestricted system-command permissions.

Adds a complete standard Apple installer containing Kumo, the local model,
agent runtime, official ClamAV components, signed virus definitions and
scheduled definition updates. It checks a harmless scan before reporting
protection ready. Normal setup failure restores the previous browser; Cisco's
separately installed components are not rolled back. Existing browser profiles
and explicit protection choices are preserved. Browser updates continue through
signed GitHub release feeds.

Install using the macOS arm64 .pkg attached to this release. Use that complete
installer for the first 0.2 installation, or to repair missing antivirus
dependencies. The browser ZIP and automatic browser updates include the local
model and agent runtime, but do not install ClamAV, its definitions or the
scheduled definition updater. Protection readiness appears in Settings → Kumo.

Known limitations:

- Widevine DRM is not bundled. Protected streaming that requires Widevine,
  including the reported Crunchyroll playback case, remains unsupported.
- Kumo's built-in Apple Passwords integration remains removed. Use a preferred
  password extension; Apple's managed browser-passkey capability is not enabled
  in this release.
- Clean-machine administrator installation, system-level upgrade/rollback,
  interrupted-install recovery and first-login readiness have not been qualified
  on a separate target Mac. Older macOS versions retain Apple's ten-minute
  package script limit; abrupt termination can leave a protected transaction
  requiring repair.
- An 8 GB Apple Silicon Mac remains the intended minimum target; whole-browser
  performance under a busy-tab workload has not been qualified on that hardware.

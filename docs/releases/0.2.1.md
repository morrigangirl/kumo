Kumo 0.2.1 fixes a crash when opening the browser's toolbar menu.

Settings, Agent Connections, and Check for Updates now use the correct native command routing. This update includes the full macOS installer with PhishLang enabled by default and the bundled antivirus dependencies.

Widevine-protected streaming remains unavailable pending licensing and integration.

Use the .pkg for a complete installation or dependency repair. Automatic browser updates preserve existing profiles and explicit protection choices; they do not install missing ClamAV dependencies. Built-in Apple Passwords integration remains removed; third-party password extensions are supported.

The installer retains the 0.2.0 qualification limits: clean-machine administrator installation, system-level rollback and interrupted-install recovery have not been qualified on a separate Mac. PhishLang remains experimental.

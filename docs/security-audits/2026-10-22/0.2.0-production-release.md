# Kumo 0.2.0 production release

Kumo **0.2.0, build `202610210004`** was [published](https://github.com/morrigangirl/kumo/releases/tag/v0.2.0-202610210004)
on **October 22, 2026 at 08:30:57 UTC**. GitHub release **420464200** is stable,
non-draft and Latest. The normal publisher exited zero. A single independent
anonymous verification finished at **08:36:09 UTC**, with no retries: all six
actual downloads matched the reviewed bytes, the normal signed-feed/browser/
package verifier exited zero, the latest appcast matched, and final release/tag
checks remained stable.

Kumo controls now belong to compiled Chromium Settings at
`chrome://settings/kumo`, native menus and the native new tab. The Kumo product
extension is removed; ordinary third-party extensions remain supported.
PhishLang and the agent runtime are bundled. PhishLang defaults on for new or
unset preferences while preserving explicit opt-outs. Agent access starts off.

## Limits

- Clean/separate-Mac administrator installation, upgrade, rollback/recovery,
  macOS 13/other older-OS execution and actual 8 GB hardware remain unqualified.
  Minimum-version metadata is not an older-OS execution test.
- Widevine is absent; Crunchyroll playback remains unresolved. Swift-wrapper
  relaunch and real desktop-provider account connections were not qualified.
- Synthetic protection fixtures establish integration, not detection accuracy.
  The pinned ClamAV source archive alone reached MaxScanTime. An optional scan
  of prior unpublished package002 returned `limited`/`archive-or-scan-limit` in
  24.77 seconds, not a malware verdict. Neither qualifies the final PKG003's
  browser download-scan compatibility, which remains untested.
- The `05:41:40 UTC` official Mac ARM64 inventory refresh still listed `.48`
  then `.47`; Kumo remains `.47`. That refresh was inventory only, not a new
  CVE/CNA audit or a claim of `.48` security equivalence.

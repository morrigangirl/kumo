## Limits and separate native qualification

This refresh uses primary Google release/source/version data and Google-authored
CNA records. Vendor fixed-version coverage is not per-CVE cross-major commit
ancestry, independent exploit execution, a fuzz campaign, or proof of no unknown
vulnerabilities. Unreleased branch-head commits and restricted/private bug
reports were not exhaustively assessed. Earlier authority records were retained,
not freshly revalidated in this pass.

Kumo 0.2 introduces new native Settings/actions, protection observers/network
hooks, agent services, helper lifetimes and installation paths. Those changes
require their own code review, completed source build, browser/runtime regression
checks and target-Mac installation acceptance. No native-browser, installer,
notarization, hardware-performance or publication pass is claimed here. This
refresh changed no source, lock, compiler setting or packaged artifact.

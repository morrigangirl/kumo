Snapshot: October 21, 2026, America/New_York; some evidence timestamps fall on
October 22 in UTC. Intended version: **0.2.0**, build **`202610210004`**.

notarization and publication are held.** Listed-host subresource fetches,
redirect targets and worker fetches reached a controlled local server despite
the domain list being enabled and ready. A separate route-free run confirmed
the shipping failure. The URL-loader-factory repair is now authored, frozen and
independently reviewed, and all 33 linked native tests passed. The rebuilt app
and runtime requalification remain pending.

checks below describe the **earlier `fab90d78…` input / `6a5373b5…` QA app**,
except the repair's 33-test execution explicitly bound to `c64192d7…` below.
They remain retained evidence and do not qualify an upcoming amended build.
This document does not approve publication or claim a notarized app/package,
an administrator installation, a personal-profile upgrade or operation on an
8 GB Mac.

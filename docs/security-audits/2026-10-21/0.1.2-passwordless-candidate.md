# Kumo 0.1.2 password integration removal

Date: 2026-10-21. Intended version: 0.1.2, build `202610210003`.

The owner requested removal of Kumo's built-in Apple Passwords integration and
authorized publishing the update without Widevine. This replaces unpublished
build `202610210002`; its signed/notarized artifacts remain preserved and must
not be published as this replacement.

## Change scope

The custom context-menu command, native credential sheet, pairing components,
settings panel, SDK probes and feature-specific test harnesses are removed.
Source preparation and compilation verify that the old custom source hooks and
copied files are absent. Chromium's normal password-related APIs, WebAuthn,
extension/native-messaging support and persistent website sessions remain.
No personal profile or custom password extension is modified. Support for a
particular extension's native Apple helper is not established by this removal.

Chromium remains `156.0.8078.47`. Existing Store consent/isolation, agent access
boundaries, dangerous-domain blocking, local download scanning and optional
PhishLang inference retain their implementations. Widevine is absent and the
reported Crunchyroll playback failure remains unresolved.

## Source verification

All 158 JavaScript/agent regression tests passed after the settings removal.
The source preparation self-test passed. All 336 offline Python tests passed,
with one expected optional pristine-source fixture skipped. Seven new regression
cases check removal during source preparation, preservation of extension and
download protection hooks, and rejection of stale credential code or files.

## Build and distribution status

A fresh source-build receipt, actual replacement runtime qualification,
Developer ID signing, Apple notarization and public update verification are
required. Those steps are pending at this source-check snapshot. Earlier
password-sheet checks and the superseded candidate's Apple acceptance do not
qualify the replacement binary.

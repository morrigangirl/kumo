# Third-party source and runtime

Kumo's MIT license covers only this project's original code. It does not relicense Chromium, ungoogled-chromium, their patches, or bundled third-party components.

- Chromium source: <https://chromium.googlesource.com/chromium/src>. Chromium's primary license and all third-party notices remain in the source archive. The running browser exposes bundled credits at `chrome://credits`.
- ungoogled-chromium: <https://github.com/ungoogled-software/ungoogled-chromium>, pinned by `config/source-lock.json`. The repository's BSD license and individual patch attributions apply.
- ungoogled-chromium macOS recipe and initial runtime: <https://github.com/ungoogled-software/ungoogled-chromium-macos>, pinned to `155.0.8059.39-1.1`. Its licensing and patch attribution remain upstream. Its original code signatures are verified before preview packaging; the modified Kumo app receives a local development signature and is not an upstream-notarized Kumo distribution.
- The optional browser QA tool is Playwright Core, under Apache-2.0, fetched into the ignored `.cache/qa` directory. It is not included in the browser application.
- The agent bridge resolves an installed Node.js runtime when it starts. Node.js is not bundled. Its own license applies.
- The native app updater uses [Sparkle](https://github.com/sparkle-project/Sparkle), pinned in `config/sparkle-lock.json`. Sparkle's MIT license and bundled external licenses are copied into the updater app as `Resources/Sparkle-LICENSE.txt`; compiled upstream assets remain excluded from Git.
- Apple SDK frameworks are system dependencies and are not redistributed in this repository.
- Known-malware-domain blocking uses the [HaGeZi Threat Intelligence Feed Mini](https://github.com/hagezi/dns-blocklists#tifmini). The published list and generated domain rules retain GPL-3.0, separately from Kumo's original MIT code. Immutable source/license pins and the transformation script are provided; packaged data includes the exact original list, full GPL license and attribution. See [the feed notice](native/malware/NOTICE.md). Downloaded feed snapshots are excluded from Git.
- The experimental local phishing feature includes a pinned PhishLang MobileBERT checkpoint converted to Core ML. Authors: Sayak Saha Roy and Shirin Nilizadeh. Its [publication](https://arxiv.org/abs/2408.05667) is CC BY 4.0. The project owner accepted that license interpretation for the authors' repository and checkpoint on October 20, 2026; this distribution decision is recorded separately from upstream metadata, which has no explicit artifact license. The underlying [Google MobileBERT](https://huggingface.co/google/mobilebert-uncased) model declares Apache-2.0. See [model attribution and port changes](native/phishing/NOTICE.md) and the bundled model notice. Kumo's MIT license does not relicense the model. Conversion dependencies are not included in the runtime application.

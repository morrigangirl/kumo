Known-malware domains · Checking

Open this panel to check protection status.

Blocks listed malware, command-and-control and other threat domains before requests. Checks stay on this Mac. The public HaGeZi threat list refreshes approximately every eight hours; browsing addresses are not sent with updates.

Threat lists can miss new threats or block legitimate sites. This layer does not scan downloaded files. macOS quarantine remains enabled.

Download antivirus · Checking

Open this panel to check the local scanner.

Downloads wait for an on-demand ClamAV scan before completion or automatic opening. Files remain on this Mac. The scanner runs one job at a time and can add memory use and download latency.

Scanner setup retrieves Cisco's official signed installer. macOS may require administrator approval. The scanner and its definitions must stay current. No detection does not guarantee a file is safe.

Local phishing warnings · Experimental

Open this panel to check protection status.

PhishLang analyzes a bounded sample of page structure and text on this Mac. Passwords, filled form values and browser credentials are excluded. No page content is sent to a cloud AI service.

Requires website access. Analysis starts after a page loads and can miss phishing or flag legitimate sites. Some page content is intentionally omitted. This model does not scan downloaded files or guarantee that a site is safe.

Security status of this preview

Chromium’s sandbox, site isolation, certificate validation, permissions, WebAuthn, and modern TLS remain enabled. This ungoogled runtime omits Google Safe Browsing. Kumo app updates use GitHub Releases; local development builds require production signing before release updates are available. It does not provide full Chrome security-service parity. Keep the engine updated before using it as your everyday browser.

Hybrid post-quantum TLS key exchange is inherited from Chromium where supported by the server. This does not make all certificates or connections quantum-safe. Legacy insecure TLS is not re-enabled.

Your keys stay with Apple.

Google website sessions persist in Kumo’s own profile. Apple Passwords remains your password vault.

The native system picker requires Kumo’s source build.

Kumo’s source includes a native “Fill with Apple Passwords…” context-menu action. In its native field, use AutoFill → Passwords to select the website or app entry and saved account in Apple’s chooser, then click Fill. This upstream-binary preview does not include that source change.

The native path uses no Apple browser extension or extension pairing code. macOS controls credential selection and may require Touch ID or device authentication. Automatic website matching and completed credential fills still require verification. Native passkeys separately need Apple’s approved browser entitlement.

Account selection stays in Apple’s chooser. The native sheet does not keep a username history or provide a separate saved-account list.

Compatibility

Standard websites, web apps, WebGL, WebGPU, WebAssembly, WebAuthn and extension APIs come from Chromium. “Web3” sites can use compatible wallet extensions; no wallet or blockchain gateway is bundled. Legacy Flash, Java, and NPAPI plugins are not supported.

Chrome Web Store downloads use Google’s store/CDN when you choose to install. Install permissions and signature checks remain in Chromium. Store installs, updates, DRM media, and managed extensions need separate compatibility verification.

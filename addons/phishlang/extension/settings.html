Before you enable it

Run install.command from the PhishLang add-on package to install the native companion. This extension starts off and asks for website access only when you enable it.

Page text and structure are analyzed locally. Filled fields, editable content, cookies and Apple Passwords are excluded. No page content goes to an online AI service. The companion starts on demand.

Experimental. The model can miss phishing and flag legitimate pages. Pages are checked after they load; this does not prevent every credential theft, scan downloads or replace Kumo’s other security controls. Private tabs and embedded frames are excluded. An 8 GB Mac has not yet been qualified.
